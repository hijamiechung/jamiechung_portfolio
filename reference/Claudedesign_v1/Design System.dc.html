Jamie Chung · Design system v0.3

Conversational behavior,
editorial expression

The archive answers questions. It does not pretend to be an assistant. Everything below exists to hold that line — borrow the behavior people already know, refuse the look that came with it.
01 · Doctrine

Inherit, redesign, reject

Inherit — behavior

A single input at the bottom of the reading column. Enter submits. Your question stays visible above the answer. Suggested openers when empty. Thread scrolls, session forgets.

Redesign — expression

Answers set as editorial prose, not bubbles. Only the visitor's question gets a container. Warm paper ground, one ink family, generous measure, a 24px baseline of quiet.

Reject — the AI product look

No assistant avatar, no gradient glow, no token-by-token typing, no model name, no thumbs up/down, no violet, no sparkle glyph, no "Regenerate".

03 · Type

Neue Montreal, two tracking values

Neutral 0% for anything read as a sentence. Tightened −1% for headings, names and small labels. No third value exists. Weights: 400 and 500 only. Switzer stands in until the licence lands.

05 · Motion

Still at rest. Precise on contact.

Motion is only permitted to explain a state change. Nothing loops, nothing drifts, nothing plays on load. Hover the rows to see each token run.

160ms · quick nav row tint, sub-item hover ease
220ms · base popover fade-rise, label fade on collapse ease / authored
320–380ms accordion height, chevron rotate, send glyph 135°→0° authored
420ms · slow sidebar width, TOC scroll tween (hand-tweened, not native smooth) authored
160ms · stepped the only pixel accent: :J dots nudge on hover steps(2, end)
120ms · press profile trigger scale 0.978 — the only "pressable" surface authored

authored = cubic-bezier(0.22, 1, 0.36, 1). Every duration halves or drops to 0 under prefers-reduced-motion.

07 · Identity

The :J mark and the icon set

Two 2.4px squares and one stroke. The face reading is allowed to be an accident the viewer finds — the mark never acknowledges it. Ceiling: 40px, one hover nudge, no eyes, no mouth, no expression set, never a mascot.

One family: 12px stroke glyph, 1.2–1.4px weight, inside a 24px container at radius 7. No filled icons, no brand logos, no monograms in the set. Rounded caps except the mark, which is square — that is the mark's only privilege.
